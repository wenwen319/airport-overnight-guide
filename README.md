# ✈️ 机场过夜场地调研 Skill（airport-overnight-guide）

一个 [TRAE](https://www.trae.cn/) 自定义 Skill：**输入任意全国机场名，自动全网调研该机场航站楼内的所有过夜场地，生成一份带场景图的分析表 HTML**。

> 适用场景：赶早班机、深夜落地、红眼航班中转——"这个机场哪里能过夜？"一句话搞定。

## 它能产出什么

输入机场名（如"广州白云机场"、"浦东"、"天府"），Skill 会自动完成：

1. **五档系统性全网搜索**（免费 → 经济 → 计时舱 → 贵宾休息室 → 楼内酒店，逐档排查不漏项）
2. **逐场地核实**：位置（具体到登机口/楼层）、安检内/外标注、价格计价方式、营业时间、购买渠道比价
3. **AI 生成场地场景图**（每个场地一张）
4. **输出一份设计感分析表 HTML**（电脑/手机自适应、可打印）

### 分析表包含

| 维度 | 说明 |
|---|---|
| 场地 | 名称 + 类型副标题 |
| 位置 | 楼层、登机口/门号，**安检内/外徽章**（深夜落地能不能用一眼看出） |
| 价格 | 实测价格区间 + 计价方式（按小时/包夜/按次） |
| 购买渠道 | 哪个平台便宜、什么权益卡免费进（龙腾/PP/支付宝钻石/航司高卡）、淘宝券 |
| 环境 | 场景示意图（AI 生成，页内注明非实拍） |
| 优点/缺点 | 一句话短语，关键条目带来源角标 |

另附「对号入座」决策卡片（穷游选哪个、带娃选哪个）和编号参考来源列表（含 URL，可溯源）。

## 安装使用（TRAE）

1. 把本仓库的 `SKILL.md` 和 `template.html` 放入项目的 `.trae/skills/airport-overnight-guide/` 目录：

   ```
   .trae/skills/airport-overnight-guide/
   ├── SKILL.md          # Skill 定义：调研工作流 + 质量检查清单
   └── template.html      # 输出模板：已确认的表格样式
   ```

2. 重启 TRAE（或开启新会话），Skill 自动可用
3. 直接说「查一下 XX 机场哪里能过夜」即可触发

## 设计要点

- **不含周边酒店**：只收航站楼内、或连廊步行直达的场地；需班车往返的一律不进表
- **时效性核查**：航站楼关闭/改造、新设施启用（如新休息室）这类变化会主动核实并写入提示
- **来源可溯源**：正文数据带角标，页脚列出全部 30+ 条来源（旅客实测帖、机场官网、预订平台）
- **权益卡攻略**：贵宾休息室档会标注哪些卡可以免费进（龙腾/PP/悦途/支付宝钻石/银联/航司金银卡）

## 文件说明

| 文件 | 用途 |
|---|---|
| `SKILL.md` | Skill 主体：五档搜索模板、数据核验要点、图片生成规范、交付前质量检查清单 |
| `template.html` | 分析表输出模板：深色表头 + 米色分组条设计，占位符替换即用 |

## 免责声明

Skill 产出的价格为各渠道公开报价与旅客实测的汇总区间，出行前请以机场官方渠道最新信息为准；环境栏图片为 AI 生成场景示意图。
